# ポケットメモ

シンプルなAndroid用メモアプリです。検索、ピン留め、色ラベル、自動保存に対応し、メモを付箋のようにホーム画面へ貼れるウィジェットがあります。

## インストール

スマホで [最新版のダウンロードページ](https://github.com/tonoyama5151/pocket-memo/releases/latest) を開き、`pocket-memo.apk` をダウンロードしてインストールします。初回は「提供元不明のアプリ」の許可を求められます。

直接のダウンロードリンク: https://github.com/tonoyama5151/pocket-memo/releases/latest/download/pocket-memo.apk

## 付箋ウィジェットの使い方

- メモを開いて上部の付箋アイコンを押すと、そのメモをホーム画面に貼れます
- ホーム画面を長押し →「ウィジェット」→「ポケットメモ」からも追加できます。追加時に表示するメモを選びます
- 付箋をタップするとそのメモが開きます。サイズは長押しで変えられます
- タイトルが空欄のメモは、付箋に本文だけが表示されます
- 編集画面の「背景」で写真か、13種類の柄（方眼・罫線・ドット・麻の葉・青海波・市松・七宝・水彩・グラデーション・紙・桜・紅葉・雪の結晶）を選べます。選ぶと色ラベルは「透明」になります
- 写真は文字が読みやすいよう明るく（白文字のときは暗く）補正して表示します
- 色ラベルの「透明」を選ぶと、背景のない付箋はホーム画面の壁紙が透けて見えます
- 色ラベルは 白・赤・黄・緑・青・透明 の6種類です
- 編集画面の「文字」はそのメモの文字サイズ、「付箋」は付箋の文字色です。付箋を貼っているメモでは、付箋ごとの文字サイズも選べます

## そのほかの機能

- チェックリスト：編集画面の上部のアイコンで普通のメモとチェックリストを切り替えます。Android 12以降は付箋の上で直接チェックできます
- ゴミ箱：削除したメモは30日間ゴミ箱に残り、一覧画面右上のメニュー →「ゴミ箱」から元に戻せます
- バックアップ：一覧画面右上のメニューから、全メモを1つのファイルに書き出し・読み込みできます
- テーマ：一覧画面右上のメニュー →「表示テーマ」で、端末の設定に合わせる・ライト・ダークを選べます
- コピー：一覧でメモを長押しするか、編集画面右上のメニューから、テキストのコピーや複製ができます
- 共有：編集画面右上のメニューの「共有」で他のアプリへ送れます。他のアプリの「共有」から「ポケットメモ」を選ぶと新しいメモになります

## 仕組み

- メモはスマホ本体のアプリ専用領域に保存されます（外部には送信されません）
- `main` に変更が入るたびに GitHub Actions が APK をビルドし、Releases に公開します
- 署名鍵 `app/pocketmemo.keystore` はこのリポジトリに含まれています。同じ鍵で署名されるため、新しい版を上書きインストールしてもメモは残ります
